# Luna Action Bars prototype

Companion addon for Retail and Forever. Disable Dominos, Bartender, ElvUI and other action bar replacements and restart WoW after installing the sibling addon link. Detected replacements automatically suspend Luna's bar management.

Open `/luit` → **Action Bars**. Select a bar with Previous/Next. Numeric entries apply on Enter. Each of the eight normal bars has icon size, spacing, linked column and row counts, center-relative X/Y, one-unit nudge buttons, square artwork, macro/binding text visibility, and a single pixel-aligned outer border. Set columns × rows to 12 × 1 for horizontal, 1 × 12 for vertical, or 2 × 6 for a block. Changing either dimension adjusts the other to fit all 12 native buttons. The Pet Bar has the same controls for its 10 buttons. Micro Menu and Bag Bar offer overall group height, X/Y, nudge controls and an outer border; their native internal arrangement and artwork are preserved, so grid and icon-specific controls are disabled. Each bar also has **Hide this bar**, independent of layout management. It hides the native bar and its mouse targets while leaving keybindings assigned. Changes made during combat wait until combat ends; once configured, a secure OnShow wrapper suppresses native attempts to show it, including in combat. Hidden managed bars retain Layout Mode handles. All settings participate in Luna settings import/export.

Use shared **Layout Mode** or `/luitbars layout` to drag handles. Handles are independent of the secure buttons. Buttons retain their native parent chain, but anchor to an addon-owned screen frame under UIParent and ignore parent scaling. No helper frames are inserted into native bar child lists. Native bar/container layout changes therefore do not resize or reposition the normal and pet action buttons. Blizzard retains responsibility for bar visibility, action slots, bindings, paging, vehicles, overrides and shapeshifting. Enable extra bars through WoW Options. The pet bar handle remains available in Layout Mode even when no pet is summoned. Stance and override bars remain outside this prototype's scope.

Luna pauses while Blizzard Edit Mode is open and restores its own layout within a second of closing it. Edit Mode changes to which bars are visible are retained; positions of managed bars belong to Luna. Disable management for a specific bar to let Blizzard control it. Disabling restores the buttons' original anchors, scale inheritance and appearance. Normal/pet bar container geometry is never overwritten. Menu and bag groups retain their native children and internal layout; only group scale and anchoring are managed.

Blizzard click handlers, mixins, methods, metatables, event registrations, action attributes and bindings are not replaced. An optional secure OnShow wrapper enforces the per-bar hide setting while retaining the original handler for normal visibility. Layout is applied at the companion's ADDON_LOADED and retried on login/world-entry. Protected changes are deferred if lockdown is already active. Combat reloads must be tested on each client: if early setup is blocked, native actions remain available and the log records the deferred layout; the intended custom layout cannot be guaranteed until combat ends. The one-second monitor refreshes settings, visible border extents and appearance only outside combat/Edit Mode. Size and position remain independent of native bar/container resets without requiring combat repairs. Combat updates touch only addon-owned border alpha; native buttons, text and cooldowns are untouched. Native cooldown anchors and callbacks are never modified.

## Diagnostics and test checklist

- `/luitbars report`: copyable report with client build, settings, actual out-of-combat geometry, pending state, security/taint checks for native update methods, anchor correction count and the last 100 events. Logs persist across reloads.
- `/luitbars debug`: toggle chat logging. Reconciliation counts in reports reveal repeated layout conflicts without flooding chat.
- `/luitbars reset`: reset all bar layouts.
- Enable `/console taintLog 1` before reproducing a blocked action; return relevant `Logs/taint.log` entries and BugSack errors alongside the report. Disable it again with `/console taintLog 0` after testing.
- Test with Dominos disabled: normal login, keyboard/mouse casting, macro changes, modifier/self casts, drag/drop, paging, druid forms/rogue stealth, vehicles, spell flyouts, Edit Mode entry/exit and Layout Mode entry/exit.
- Enter combat after setup, verify casting and paging, reload during combat, then verify keyboard and mouse actions again before leaving combat. Capture a report immediately afterwards.

This is a prototype, not a claim of zero taint. Mock tests cover guards and lifecycle behavior; only the WoW client enforces secure execution.

When Luna resumes managing a bar after native Edit Mode or a disabled period, it captures the current native button geometry. Disabling management subsequently restores that latest layout.
